# S18 真外部主体否决：让规约第 41 行失效

复算：`python external_veto.py demo` ／ `python external_veto.py isolation` ／ `python amend.py history` ／ `python fireup.py check`

## 一、这一版到底改了什么

原来有三个东西混在一起：闸（能不能立）、审签（有人看过）、提交（生效）。规约第 41 行自陈的就是第三个错——“提交即生效”。

这一版把第四段补上了，并且是**硬接线**，不是加一句话：

1. **外部入口只看公示稿**（`external_veto.py`）。公示稿里只有公开字段：提案是什么、谁受影响、公示到几时、怎么否。外部进程不 import 内账模块、不读 `cases\`／`checks\`／`ledger\`。
2. **`amend.py commit` 必须凭公示放行**。没有外部侧记下的「可生效」记录，无论审签多齐、文本多一致、基因锁多完整，一律拒绝（fail-closed）。
3. **规约第 41 行改写为 v10**，这件事本身走完了 提案→两份复核→公示→期满无否决→生效 的全链。

## 二、三个数

**数一：外部提交 3 次｜资格成立 2｜资格不成立 1｜中止 2｜放行 2**

| 公示稿 | 提交者（凭据） | 结果 |
|---|---|---|
| V1 补偿费由镇代管 | 院上村村民委员会（主体:名单内） | **受理 → 中止** |
| V2 永基 0.1936 公顷不落图 | 地块4相邻权利人（相邻:名单内） | **受理 → 中止** |
| V3 规约第 41 行修订 | 路过群众（主体:不在名单） | **拒·不受理**（被拒也留声） |

三个都是独立进程、argv 里只有公示稿和自己的凭据。资格判据是「名字必须精确落在公示所列名单内」，不做模糊匹配——V3 的受影响名单里只有“张店·本人”，路过群众进不去。

**数二：未公示直接提交 → 拒（exit 2）**

审签 2/2、reject 0、拟议文本摘要与提案登记一致、基因锁四款逐字在——结果照样：

```
公示校验：✗ 提案 P-20261122-095847 未出公示稿 → 缺公示期，拒绝生效
✗ 缺公示放行记录 → 提案不得生效，规约保持原样（fail-closed）
```

这是“提交即生效”真正死掉的地方。之前 publicity.py 里那个“期内被否决”只是演示流程，amend 根本不看它；现在 commit 直接读外部账，读不到就拒。

## 三、代价：改自己必须留声，这次真跑了一遍

改 `amend.py` 是要害动作。第一次改完，闸 1 立刻红：

```
✗ amend.py 指纹不一致  期望 8408fff8…  实际 7e397a7f…
结果：✗ 校验器本体被改动，拒绝点火（闸1）
```

必须走 `init --rekey`，并且原因必填、条数不得少于创世锚基线。`anchor/rekey_log.jsonl` 现在 3 条，两条是这次的：

- 「S18：amend commit 增加公示放行校验——未取得外部『可生效』记录者不得生效（使规约第 41 行自陈失效）」
- 「S18 收尾：公示账位置允许 PUBLIC_STATE 覆盖（供沙箱测试构造放行记录，不碰真账）」

规矩没有替我省事：想改校验器，就得把改的理由写在谁都删不掉的账上。

## 四、诚实边界（这几条比结果重要）

1. **“外部主体”仍是我写的脚本装的三个人**。隔离做到的是“入口不接线”（自检：内账模块 import 0、读过文件 2 个全在外部账内、内账 0），不是操作系统级隔离。同机同用户，理论上能绕。真正的检验得等真人：把公示稿挂到公告栏上，让村委会真的来否一次。
2. **资格判据只到名字精确匹配，没有实名**。谁都能自称“院上村村民委员会”。这是当前最大的洞——它意味着否决权可以被冒领。
3. **公示期 3 拍是我们自己定的，不是日历**。真人看一份公告、找依据、写否决，三天都不一定够；3 拍在真实时间里等于没有。
4. **被否了就死，没有复议**。V1/V2 中止后再没往前走；`publicity.py` 里那条“改后重提再公示”的链，外部入口这边还没接。
5. **第 41 行里“尚未做到”三项是我写的，不是系统算出来的**——它们只在文档里，没进校验。

## 五、对“网络大模型”这件事的意义

这是第一次，规约的变化不是我想改就改的：我想让第 41 行失效，得先造出不读内账的外部入口，再让 commit 认这个入口的账，再走一遍完整公示链。**规则反过来约束了造规则的人**——这才是“解码约束”真正在起作用，而不是一段自我声明。

同时暴露一个结构事实：闸、审签、公示是三件不同的事。闸问“立不立得住”，审签问“有没有人看过”，公示问“有没有人反对”。三者齐了才叫正当；缺公示，前两者再漂亮也白搭。
