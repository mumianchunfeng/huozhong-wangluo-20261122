# 远景：整个网络运行整个模型

**终局一句话**：不是把一个大模型部署到很多机器上，是**让每一个节点都持有同一份可复算的账，谁上线谁织网，网本身就是模型**。节点是神经元，触须是突触，事件是脉冲，账是记忆，规约 root 是这个物种的基因。

这一版做不到全球。现在的位置必须写清楚：

| 项 | 现在 | 终局 |
|---|---|---|
| 节点数 | 1（本机）＋ demo 里 3 个模拟 | 全球任意自愿节点 |
| 传输 | 目录信箱（同机／同盘） | 公网中继或点对点 |
| 发现 | 手写 `peers.json` | 目录服务／DHT／邀请链 |
| 身份 | 随机 node_id | 持钥身份＋可验证签名 |
| 冲突裁决 | 本机 K1–K4 | 跨节点仲裁与分层复核 |
| 数据 | 张店区 9 件公告 | 多法域、多语种、多事实源 |

**但这六道坎，现在就得留口子，否则将来拆不动。** 已经留的：

1. **协议版本**（`tentacle/1`）：换协议时旧包被明确拒收（进《异宗账》），不会悄悄读错——这一条本版已加。
2. **按键去重，不按序号**：事件键是「件|格」，不是自增号；将来多节点乱序到达也能对齐。
3. **同宗判定只看 root**：不认 IP、不认主机名，换个地方跑、换个 ID，只要规约 root 一致就还是同一个物种。
4. **账与判据分离**：换判据不动账、换模型不动账——全球节点口径会分化，账必须能共处。

还没留、将来必须补的四件（本版明确没做）：

- **签名身份**：现在 node_id 是随机串，可被冒名。全球尺度下必须节点各自持钥，事件带签名。
- **增量与寻址**：现在整包交换，45 条无所谓；全球是百万级，必须 Merkle 树／按格订阅。
- **中继与穿透**：现在只能同盘信箱；公网要中继，或打洞直连。
- **跨法域合规**：征地数据出了县就不一定合法；全球网必须按法域分域，不是所有节点都该拿全量。

**设计纪律（防止将来造反）**：

1. 现在每一处“为了跑通”的简化，都要在文档里写成“待补”的显式条目，不许当成已完成。
2. 任何为全球规模准备的结构（协议版本、键、root 判定），现在就要生效并在 demo 里被跑到，不能只写在纸上。
3. 不许为了“看起来像大模型”去堆假节点：模拟节点只在 demo 里出现，账里永不计入真实节点数。

**信念落在哪**：不在口号里，在两条已经跑通的机械事实——①同宗即可织（root 一致就并入）；②异见不静默（同格不同判必记冲突）。这两条能撑到全球，其余都是工程。
