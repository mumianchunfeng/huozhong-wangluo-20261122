# S21 免疫层（仿生学机制）· 结论

日期 2026-11-22｜来源：另一 agent 打磨成果（`H:\C盘Users888Desktop\新建文件夹`），已并入本工程。

## 一、它补的是哪个洞

触须的同宗判定只看规约 root。root 是公开的，谁都能抄——**同宗证明不了自己人**。免疫层不认 root，认行为：你判过哪些格、判成过还是判成否，这是表面标志（MHC）。

## 二、四段机制

1. **行为谱**：`sig` = 该节点历史判定（`件|格` ＋ `过/否`）排序后 sha256 前 16 位。
2. **首次应答**：新 node_id 的包先隔离，事件不进联邦账——可看不可信。
3. **二次应答**：同节点连续三拍一致，滴度到 `MATURE_AT=3` 才成熟，隔离事件一次性并入。
4. **异己反应 ＋ 克隆选择**：成熟节点把历史格翻转 > `FLIP_TOL=2`，判「换了皮的人」，滴度 −1、进警戒账、当次隔离；覆盖率 < `COVER_MIN=0.8` 的包不并。

账在 `触须\免疫账\{身份档案,隔离账,警戒账}.jsonl`，不动联邦账。开关 `LW_IMMUNE=1`，**默认关**。

## 四、我修的集成缺口

`demo()` 原来每节点只投一拍，与免疫默认政策天然冲突（新节点首包必隔离）。已改为**同一节点连投三拍**（`A-0/1/2`、`C-0/1/2`），并打印「B 第 k 拍」。免疫关时多投的两包走重复路径，新增 0，对旧数没有影响；免疫开时前两拍拦截、第三拍成熟。

## 五、诚实边界三条

1. **不防拟态攻击**：把别人历史行为全镜像一遍，行为谱一样，分辨不了。
2. **只判行为像不像，不判内容真假**：真假仍归三层校验器，免疫只管「谁配进来」。
3. **仍是可冒名的身份**：node_id 随机非实名，真认证要各自持钥（签名身份仍未做）。
