# 公示期与否决通道：接上了

2026-11-22　`I:\agent运行时\活网\阶段三\publicity.py`

## 状态机

```
提案 ──三层闸──✗──▶ 闸拒（不进公示、不进账）
              └──✓──▶ 公示期（3 拍）──期内被相对人否决──▶ 否决账（不得生效，留声）
                              └──期满无人否决──▶ 生效账（带公示记录）
```

三条纪律：闸过的才进公示；进过公示的才可能生效；闸与否决是两本账，不混算。

```
三本账：公示中 0 / 生效 2 / 否决 1
```

## 最要紧的一件：P02 证明「闸看不见的，否决能看见」

P02 的补偿段写「约163.13万元，由**房镇镇人民政府代管**后统筹使用」，三层闸全过——关系表查到「给谁」是院上村与农户，域表查到货币＋养老，跨表算式算出来也对 163.13。

但钱要过镇政府一道手，这事闸判不了：它不是算错，也不是主体错，而是**通道错**。相对人在公示期内一句「补偿费应拨付本村账户，镇代管无依据；分配须由集体经济组织成员讨论决定」就把它拦下了，依据是公告四（一）。这条理由写不进任何一格的判据——它是只有利害关系人才说得出的东西。

这就是公示期存在的理由：闸管「能不能立」，否决管「该不该行」。

## 顺手抓到一次自己人的错

跨表算式一接上，P01、P03 第一版全被闸拒：`[跨表] 补偿段里找不到金额`。查下去是「真事-跨域.json」里法律域那条正确补偿值根本没写金额（只写了“拨付村委会账户”）。

这不是判据错，是**值缺要素**——第三层第一次抓到的不是“谁写错了”，是“我们自己的正确样本不全”。补上「约163.13万元」之后才通过。v1、v2 的三版对照重跑，数字未变（0.90 / 0.60 / 0.90，重学 15 / 44 / 6）。

## 与规约对账

第 6 款要求的三件——**可复算、可公示、期内无人否决**——本地口径下都齐了：闸三层可复算，公示期与到期日志在 pending/events 两本账，否决留了人、时、理由、依据。

但规约第 41 行那句仍然成立：**本地提交不产生正当性**。因为否决人「院上村村民委员会」是我写在脚本里的字符串，不是独立主体；公示期是拍数不是真实日历。所以这次接上的是**通道**，不是**正当性**。

## 边界

1. 单机仿真：一个提案人（张店·本人）、一个相对人（脚本扮演）、3 拍公示期。
2. 否决不可上诉、不可复议：现在只有「改后重提＝新提案」，没有裁决层。
3. 否决权重未定：谁有权否决、几票算数，规约只写「任何受影响者」，本件未定义受影响者的认定方式。
4. 生效账只记五格与公示记录，没记「谁核过、核到哪一步」。
