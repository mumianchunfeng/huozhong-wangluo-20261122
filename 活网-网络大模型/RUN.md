# 活网 · 网络大模型 v1（2026-11-22 打包）

**这是什么**：不是 LLM。词表＝8 域 × 18 关系 × 账本条目；判断靠三层校验器；冲突靠批评者权重＋阈值＋逾期；正当性靠公示—异议—复核；账可离线自证。模型可换，账不换。

**先说没有的那件事**：它**没有部署到任何网络、没有常驻进程、没有对外入口**。这一包是在本机跑通的完整工程，外部主体、网络节点都是脚本里的登记名。要让它在网络上跑，必须先有第二台独立机器和第二个人——本包不假装已经有。

- 要求：**Python ≥ 3.9，仅标准库**（无第三方依赖）


## 5. 切分方案（一句话）

按 **「词表 → 判据 → 裁决 → 账 → 介质」五层竖切**：词表管“说什么”（8 域 × 18 关系 × 条目），判据管“对不对”（关系表／域表／跨表算式三层），裁决管“该不该行”（批评者权重、阈值、逾期），账管“记什么”（事件流＋状态＋公示视图），介质管“放在哪”（I 盘／移动硬盘／纸质，三处不同室）；**改判据不动账，换模型不动账**。

## 6. 转移机制（一句话）

**整个目录就是转移单位**：复制本目录到任意非 C 盘路径（不写注册表、不装依赖、不联网），在新位置 `python run.py` 八步全过即转移完成；账包内 `verify.py` 复算哈希与金额，对不上就拒用。

## 7. 触须对接（S20）：跑一次就织一次

**为什么必须加**：不伸触须，它永远是单节点——样本只能靠自己攒，冲突只能靠自己扮，壮大的只有文件体积，不是网。

**五条铁律**

1. **同宗才认**：规约 root 必须全等；改一个字节就只进《异宗账》，登记但不并入。
2. **只搬事件，不搬权威**：外来的是「某节点对某格判过/否」，进《联邦账》，**不覆盖本地账**。
3. **同格不同判 → 记冲突**：进《冲突账》，标节点依赖，交 K1–K4 裁决，不静默平均。
4. **去重靠 (节点, 键)**：同一个包导两次，0 新增。
5. **身份不是实名**：node_id 随机 ＋ 账指纹认宗，可被冒名——真认证要各自持钥。

**命令**

```powershell
python model\tentacle.py status     # 节点数／联邦事件／冲突／水位
python model\tentacle.py demo       # 自演：同宗并入→异见冲突→重复 0→异宗拒收
python model\tentacle.py bundle     # 只伸不投（包在 触须\out\）
python model\tentacle.py absorb --bundle X.json
```

`run.py` 第七步会自动调 `tentacle.py beacon`：**首次运行自建身份**，有对端就投包并收包，没对端就如实报「单机模式」。

**对端清单 `peers.json`（放包根；不配＝单机）**

```json
{"peers":[{"name":"对端B","inbox":"D:\\活网B\\model\\触须\\inbox"}]}
```

**实测（`tentacle.py demo`）**

```
节点 3｜联邦事件 90 条｜覆盖格 5 类｜冲突 24｜异宗包 1｜本地水位 45
重复导入同一批事件：新增 0｜重复 45｜账行 90→90
冲突样例：ZD08|harm、ZD08|rule、ZD08|who
```

那 24 个冲突来自**同一批事实、两种口径**（v3 认字段 vs v2 认字）——不是数据错，是判据不同；这正是网络该记下来、并交给裁决层的东西。

**它靠什么壮大**：不是参数，是**节点数 × 每节点独立判过的事件 × 冲突被裁决后沉淀的口径修正**。同一格被越多独立节点判过，摇摆格才可能收敛成共识。

**做不到的（诚实三条）**：不自动发现对端（地址要写进 `peers.json` 或人工投包）；只做目录信箱、不跨公网（要过网得自己加一层中继）；node_id 可被冒名。

## 8. 免疫层（S21，仿生学机制）

**它解决什么**：触须的同宗判定只看规约 root——root 是公开的，谁都能抄，所以「同宗」证明不了「自己人」。免疫层不比 root，比**行为**：你过去判过哪些格、判成过还是判成否，这就是你的表面标志（MHC）。

**四段机制**

1. **行为谱**：`sig` ＝ 该节点历史判定（`件|格` ＋ `过/否`）排序后的 sha256 前 16 位。它不认名字，只认「你判过什么」。
2. **首次应答**：没见过的 node_id，包先隔离，事件不进联邦账（可看不可信）。
3. **二次应答**：同一节点连续**三拍**判定一致，滴度累积到 `MATURE_AT=3` 才成熟，隔离事件一次性并入。中途改口就永远长不大。
4. **异己反应 ＋ 克隆选择**：已成熟节点若把历史格翻转超过 `FLIP_TOL=2`，判为「换了个人的皮」，滴度 −1、进《警戒账》、当次隔离；覆盖率不到 `COVER_MIN=0.8` 的包不并。

```powershell
python model\immune.py status
python model\immune.py selfcheck      # 三只羊：诚实 A／冒名 B／突变 A，全在临时目录
python model\immune.py guard --bundle X.json
$env:LW_IMMUNE="1"; python model\tentacle.py demo    # 免疫开启跑同一套自演
```

**默认关闭**：不设 `LW_IMMUNE=1`，触须老路径一字不改（这就是为什么老数 3/90/24/1 一点没动）。账在 `model\触须\免疫账\`，与联邦账、冲突账分开，删了不影响织网。

**两条实测（都验过）**

- 免疫开、只投一拍：`节点 1｜联邦 0 条｜冲突 0`——新节点首包全被隔离，**网织不起来**。这不是 bug，是首次应答的定义。
- 免疫开、同一节点连投三拍：`节点 3｜联邦 90｜冲突 24｜异宗 1`，与免疫关完全同数，但**多了一层「谁配进来」的筛**。

**做不到的（诚实三条）**：不防「拟态攻击」——把别人的历史行为全镜像一遍就分不出来；只判行为像不像，不判内容真假（真假仍归校验器）；node_id 可冒名，真正的身份要各自持钥（见第 10 节）。

## 9. 伦理底盘与私有技能隔离区

`ethic_root.md` 是**备注层**，与《本源规约》同级但**不进基因锁、不参与全文哈希**——因为规约正文一改一个标点就作废对外锚，伦理若只能靠「凑两份审签」写进去，它自己就先违了无单钥那一款。

四条硬约束：**权属**不绑定任何主体、寄存网络本身；**私技隔离**——校验、裁决、自进化只用通用骨架，18 种关系界定／貔貅调度／活字复用／逆向取证不打包、不触须同步、不随包扩散；**分发纪律**——只传可核验事实包、异议、复核裁决、冲突账，握手只验基因锁、不夹带私技签名；**目的锚定**——无预设主人，能力增长不产生权限。

两条图（`F:\Obsidian法律知识库\Excalidraw\`）都把这个隔离区画成**独立分支、无箭头接入构建线**：不是漏画，是隔离。

## 12. 边界（不粉饰）

1. 未上网络：没有第二个独立节点，没有真实外部主体；否决与复核仍是本机脚本扮演。
2. 样本 9 件、6 村（独立 7.5），同区同年同模板；不证明跨区跨省。
3. 4 件金额由面积×单价算出，属自证；真正写明金额的正例只有 6 号 1 件。
4. 阈值系数 0.6/0.5 是设定值，不是从数据学出来的。
5. `external_veto` 的复核主体仍可能与提案人同体——v11 自陈的一号洞未补。
6. Ⅲ 级区片单价空缺；8 号数字取自扫描页 OCR，未逐字核 PDF。
7. 免疫层默认关；它不防拟态攻击（镜像全部历史行为即分辨不了），也不判内容真假，只判「谁配进来」。
8. 真实节点仍是 1 台机器；`demo` 里的 3 个节点只做机理验证，不算网络规模。
