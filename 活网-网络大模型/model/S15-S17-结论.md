## 一、S15 换了五条规则

| 代号 | 规则 | 参数 |
|---|---|---|
| R1 | 学习率：命中 score←score+α(1−score)，失手 score←score−α·score；票重＝base×clamp(0.5+score, 0.5, 1.5) | α=0.25 |
| R2 | 衰减：一轮不表态 score←score−γ | γ=0.03 |
| R3 | 阈值会动：sustain=max(3, round(0.6·ΣW))，respond=max(2, round(0.5·ΣW)) | 系数设定，非学出 |
| R4 | 逾期：标「需回应」最多挂 2 拍，第 3 拍无补证 → 异议失效、事项转「生效（逾期）」 | TTL=2 |
| R5 | 回避：提案人不得作本议题批评者投票，净权重与分母同步剔除 | — |

## 三、判读：两个病，两味药

- **S19 的病是「堵」**：18/19 卡在需回应。压掉它的是 **R3 阈值会动**（2 票喊话不再自动进「需回应」档），学习率对此毫无作用——所以别再拿「加样本」当解法。
- **S10/S15 的病是「寡头」**：旧规则命中率 100% 直接 ×1.5，C1、C2 各自 3.0，**单独一票即否决**——实测 19/19 全被单方否决。这才是「无单钥」被架空的真实样子。学习率把它修成「连续命中才慢慢顶格」。
- **顺序敏感是硬事实**：C2 首次只到 1.94，因为第一件（ZD06）只有 T1，C2 沉默一次即被衰减。学习会记顺序，换一批次序结论会动。
- **TTL 是 fail-open**：2 拍内没人补证，事项就放行。选它的理由与 v11 同源——外部没有杀死权，也不该有无限拖延权；真受损方要保住异议，得在期内拿证据。

## 五、边界（写清，别当成已解决）

1. **阈值系数 0.6/0.5 是我设定的**，不是从数据学出来的；每格观测仍只有 9 条，学不出权重。这版是「手工调好的规则」，不是「学出来的规则」。
2. **回避只在 `learn.py` 里模拟**：`external_veto.py` 的 `review` 主体仍可能与提案人同体——v11 自陈的「复核人即提案人」这个洞**仍未真正补上**，S15 只证明了规则长什么样，没有改端口。
3. **TTL 变体只测了模拟档**：真实账里没有「有人补证/撤回」的记录，19 个议题全按沉默处理。
4. **账包只证完整性，不证真实性**：8 号数字取自扫描页 OCR 未核 PDF；批评者是登记名不是真人；公示稿与内账的**语义一致**（而非仅哈希）没有离线验算器能验。
5. **三处不全**：处 2 需要你插移动硬盘，处 3 需要真的打印封存。脚本不能替你做物理动作，也不会假装做了。
