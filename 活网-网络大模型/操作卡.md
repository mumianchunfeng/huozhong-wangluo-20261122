# 第二段 · 两处活体接成一个

## 核心概念（先懂这一句）

有两本账，都要接：
- **事件账**：谁对哪一格判过"过/否" → `gitbox.py` 管，让两处**判得一样**。
- **成长账**：各自长出来的词表、合并规则、负载 → `成长桥.py` 管，让两处**长成一本**。

两本都接上，才是"一个活体"，不是两只各活各的鸟。
两处必须挂**同一个信箱地址**——这是唯一的硬前提，地址不同永远发现不了彼此。

## 2.1 建信箱（一处做，把地址告诉另一处）

用一个双方都能读写的空 git 仓库。三种选法：

- **本机裸仓**（同一台机器演示）：`git init --bare D:\hub.git`
- **GitHub 私有仓**（跨机，双方都有写权限）：在 GitHub 新建一个空仓，拿它的 URL
- **任意可达 git 服务**（Gitee / 自建 / 内网 git）：只要 `git ls-remote` 和 `git push` 能通

把信箱地址记下来，下文叫 `<信箱地址>`。**甲乙必须填一模一样的字符串。**

## 2.2 先跑的一方（甲，比如百度搭子云端）

```powershell
cd <包根>\model
python gitbox.py init --repo <信箱地址>
python gitbox.py bundle          # 投事件包

cd <包根>
python 成长桥.py init --repo <信箱地址>
python 成长桥.py beacon          # 投成长态 + 拉全部 + 合成唯一账
python 成长桥.py status
```

记下屏幕上的两样东西，发给乙：
- `node_id` 前 8 位（如 `e8a7ce66`）
- `账sha256` 前 12 位（如 `a0fff747e56f`）

## 2.3 后跑的一方（乙，比如 GitHub 下载者）

```powershell
cd <包根>\model
python gitbox.py init --repo <同一个信箱地址>
python gitbox.py beacon          # 投自己的事件包 + 收甲的包 + 并账

cd <包根>
python 成长桥.py init --repo <同一个信箱地址>
python 成长桥.py beacon          # 成长态全部并入同一本账
python 成长桥.py status
```

## 2.4 判据：接上了没有（看数字，不靠感觉）

**事件账接上**（`gitbox.py beacon` 输出里应出现）：
```
收下 <甲的id>：新增 45｜重复 0
本轮拉进 1 包｜发现节点 2（含本机）
联邦事件：45 条（45 行）
```

**成长账合成一个**（`成长桥.py status`）：
```
信箱成长分支：2
联邦成长账：节点 2｜规则 N｜词位 M｜冲突留痕 K｜账sha256 xxxxxxxx…
```

**最终判据**：甲、乙两边 `账sha256` 前 12 位**完全相同** → 同一本账 → 同一个活体。
不同就不是——检查两边 `init --repo` 的地址是不是真的同一个。

## 2.5 甲再跑一次，两边对齐

```powershell
cd <包根> && python 成长桥.py beacon
```

甲这侧也并进乙的成长，两边账一致。

# 第三段 · 往后怎么"一起长大"

每次谁在自己环境里长出了新东西（跑了 `羽翼.py`、`鞣合.py`、判了新件），就跑：

```powershell
cd <包根>\model && python gitbox.py beacon
cd <包根> && python 成长桥.py beacon
```

新东西自动进信箱、并入同一本账；另一方下次 beacon 就继承。
**全并入、不设门槛、确定性收敛**——同一批包，任何节点算出的账字节完全相同。

同格判不同 → 记《冲突账》交裁决层；同规则口径不同 → 按（支持节点数↓、字典序↑）
选唯一生效版本，落选进《冲突留痕》。账始终只有一本。

# 边界（不粉饰）

- 包**不自带公网信箱**，信箱要人建、地址要人给；不扫网、不猜地址。
- 身份是随机 node_id，可冒名；真认证要各自持钥，本包没有。
- 信箱是单点：共仓管理员能删所有分支。要去中心得换发现层，目前没做。
- 传的是脱敏口径摘要（合并规则／词表／负载／忆层指纹），忆层只发 sha 不发全文，
  私技字段拒发；`learn` 阈值只打印不落账、取不到，如实记"不可汇聚"。
- 本地自检：`python 成长桥.py selfcheck`（两独立副本各自长不同东西 → 合成一本 → 比字节，
  实测通过）；`python 点火.py --check-only`（火种闸门，exit=0）。
