# 跨域对照：经验挂在谁身上

2026-11-22　`I:\agent运行时\活网\阶段三\`

## 改的只有一处

`netmodel.py` 的 `cmd_cross()`：同一件真事、同一套判据，只换 state 的学习键——
`--key domain` 经验按域存（换域清空，即原来那行 `s["slots"] = []`）；
`--key relation` 经验按关系存（换域可带走）。
A 段在同域学满，B/C 段换两个域，看换域首拍还剩几项站得住。

## 三行数（`python netmodel.py cross-both --n 30 --seed 20261122`）

```
键=域　　｜换域首拍保持 0/5（全部归零）｜分项保持 给谁 0.00，按什么规则 0.00，依据哪份数据 0.00，谁受损 0.00，如何补偿 0.00
键=关系　｜换域首拍保持 2/5（给谁、谁受损）｜分项保持 给谁 1.00，按什么规则 0.00，依据哪份数据 0.00，谁受损 1.00，如何补偿 0.00
判定：跟着关系走 = 给谁、谁受损；跟着域走 = 按什么规则、依据哪份数据、如何补偿```

## 怎么读

- **「给谁」「谁受损」是关系级的**：权利人是谁、谁的什么被减损，不因看它的视角而变。所以按关系存，换域仍 1.00。
- **「按什么规则」「依据哪份数据」「如何补偿」是域级的**：同一件征收事，法律口径引 112.5/135 与鲁政字〔2023〕144号；政务口径讲 30 日公告期、听证、补偿登记；金融口径看专款拨付到村委会账户、约 163.13 万元。三项各有一套，换域必重学，保持率 0.00。
- **因此 144 格压不到 18 格。** 可压的形状是：18 个关系 × 2 项 + 3 个域 × 3 项 = 45 格，而不是 8×18=144。按关系统一存，反而每换一个域就要把三项重学一遍，跨域段通过 0.30 低于域键的 0.45（这两个总数含重学费、子键数也不同，不作证据，只作旁证）。

## 边界（这条必须先说）

1. **判据是我按现实判的，不是实验发现的。** 哪两项算关系级、哪三项算域级，写死在 `cases\真事-跨域.json` 的 `common` / `domains` 里。实验确认的是「按这套判据，关系键确实带走这两项、带不走那三项」，不是替我判出层级。
2. **只有 1 件事、3 个域、4 个关系、30 拍。** 换别的域（医疗、航空、能源）或别的案子，三项的划分可能变。
3. **总通过率不可直接比。** 域键只有 3 个块、关系键有 4 把子键，重学次数天然不等；证据只用「换域首拍保持率」与「分项保持率」。
4. 这里测的是「经验能不能带走」，不是「写得对不对」。对错仍由外部校验器判，跟前面真事那一跑同一口径。

## 对「网络大模型」的一句话

它成立，但形状不是「18 个中 token 复用到所有域」，而是**两张表拼一张**：关系表管「给谁、谁受损」，域表管「规则、依据、补偿」。域不是前缀，域是三个栏目各自的坐标系。下一版词表若照这个改，规模从 144 降到 45，且换域不再归零——归零只发生在该归零的那三项上。
